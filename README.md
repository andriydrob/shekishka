# Шекішка

Настільна гра на 2–4 гравців з кубиками: проведи 4 фішки по колу й заведи їх у свій рукав.
Гра проти ботів (легкий / середній / важкий) або кількох людей на одному пристрої.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run dev -- --host   # щоб відкрити з телефона в тій самій Wi-Fi мережі
```

## Структура

- `src/game/board.ts` — розмітка поля 13×13 (кільце 48 клітинок, П, В, тюрми, рукави)
- `src/game/engine.ts` — правила як чисті функції `(стан, дія) → новий стан`
- `src/game/bot.ts` — боти трьох рівнів
- `src/ui/Board.tsx`, `src/App.tsx` — інтерфейс

## Тести

```bash
npx vitest run
```
